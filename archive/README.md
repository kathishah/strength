# Retired v0.2 prototype

This directory contains the original static micro-session prototype and its supporting notes and assets. It is archived and is not the current application. The current app lives in `app/`; start with the [root README](../README.md) and current product spec at [`docs/SPEC-strength.md`](../docs/SPEC-strength.md).

`routine_micro.html` links to exercise GIFs on third-party sites rather than including them. Nothing in this directory or in the app uses those files, and [the media rights audit](../docs/MEDIA-RIGHTS-AUDIT.md) records them as not cleared.
