How it is built

A static app with an event log.

Every set you log is an event appended to a log in the browser. Sync, when you add it, copies those events to storage only you can read.

Fig. 1The app runs without the dashed box. Add it and each device pushes and pulls the same events, filed under your own Cognito user ID.

Notes on this page

All workouts, weights and dates shown here are fictional. The demo is a sandbox in your browser. The private instance at strength.logbook.me is separate and is not the demo or a service for forks. Code and documentation are MIT licensed; exercise images are excluded.
